# Proposed additions for docs/local-models.md (controller integration only)

MAIN admits one llama.cpp server at a time. `scripts/local-models/start.ps1` starts the default 9B model; `-Model local/qwen3.6-35b-a3b` selects the other model explicitly. CLI and app startup share a machine-wide admission mutex on loopback port 51434. A matching authenticated running model is reused; another model is refused with its name. Conductor never evicts the running model automatically. Finish its work and explicitly stop it before switching.

Admission checks configured and recorded ports, including moved/adopted servers, and inventories running llama-server processes before allocating another model. Dead PID plus unused port means a stale run record; no process is killed and the stale record does not count as residency. An unreadable record, unknown listener, inaccessible process inventory, unavailable RAM/VRAM telemetry, or an unreviewed memory configuration fails closed. A process crash releases the admission mutex automatically; a slow startup never loses it to a timer.

Memory admission uses pinned GGUF sizes, context/KV growth, GPU offload and runtime/desktop reserves. These conservative estimates are not actual allocation measurements. Extra llama.cpp arguments require reviewing their memory impact before startup is allowed. Existing authenticated servers remain reusable even when measurement tools are unavailable. This implementation targets MAIN/Windows; new starts on other platforms require a supported process-inventory implementation.

Measured 2026-09-21 on the existing server, `/props` reported `b10901-28ff09582`, one slot, 32768 context. Default chat-completion requests already reused prompt/KV cache within a conversation and across two alternating histories. No cache flag, server restart, or slot-count change was needed. See `artifacts/swarm-2026-09-21/local/findings.md` and raw JSON for the distinction between full prompt usage, cached tokens and evaluated prompt tokens.

Developer measurement command: `node --experimental-transform-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/local-models/measure-thrift.ts`. It uses the already-running 9B only, executes bounded fixture file tools under its artifact directory, and never starts/stops servers. It advertises the current tool schemas but disables Docker commands and app-control mutations in the fixture; that limitation must accompany any reported acceptance result.
