### Other finding (not an item of this round, one conversation)
- **A local conversation whose turn stopped "blocked" never gets a fresh task budget.** `agent.ts:595` starts a new execution only when the last one is `completed` or `cancelled`. After Dolphin burned 72 rounds in 3 stagnating turns (swarm run 4, "Controller B2"), each of the next **12 owner requests** ended at once with "Could not complete the task: The cumulative limit of 72 tool rounds was reached" and 0 calls. Fresh tabs in the same run worked. A small model stagnates often, so an ordinary conversation can end up permanently unable to use tools. `B2-run4.json` holds the evidence. A unit test: after a `round_limit`/`stagnation` finish, the next `run(prompt)` gets `maxRounds` again (or the owner is told to open a new conversation).
