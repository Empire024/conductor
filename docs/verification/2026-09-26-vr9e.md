### Finding (recorded, not a reopen, per the controller)

**The one-time legacy recovery reads only the last 2000 timeline items.** `recoverFromTimelines`
(`src/main/permission-grants/wiring.ts`) reads `store.snapshot(id).items`, the projection that
`MAX_TIMELINE_ITEMS = 2000` (`src/shared/structured-agent-reducer.ts`) trims. S1b: the OLD wizard filed, then ran a
`SYNTHETIC LONG 3000` turn. Its projection held 2000 items, truncated, without the card, while the old build still
held the request pending. After the update the request was gone: not in the owner's state, not in W's list, and the
first permission-grants.json was written with `requests: []`, so no later launch can take it back. 2/2
(`L-after-1`, `L-after-2`); control S1n (card inside the window) PASS 2/2. This applies only to cards filed before
4781e54: cards filed on this build restore from permission-grants.json, which S2 shows is independent of the
timeline. The owner's B5 card has about 450 items after it (the controller checked agent_muhp8yjs: 2548 events,
B5 at about sequence 2100), so it is inside the window. A fix, if wanted: read the holder's journal
(`structured_events`, per-session and indexed) for `grant:` cards instead of the projection, or do not write an
empty file when recovery found nothing.
