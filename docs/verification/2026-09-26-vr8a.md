### Failing scenarios for the next batch (tests to write)
- **A3**: under a wizard, an Ask-mode coworker's **first** `npm test` (and a first Edit inside the workspace) must be
  answered without a reviewer turn (0 reviewer prompts). Today every first-of-class request costs one review; only
  repeats are free. Reproduce: `node scripts/smoke-lock.mjs --timeout-min 20 -- node scripts/smoke-verify-vr8a-approvals.mjs --only synthetic` → row A3-synthetic.
- **A4**: a Claude `Write` whose parent folder does not exist yet (`notes/todo.md` in a fresh repo) must be reviewed
  like any other workspace write, not paused to the owner. Cause: `src/main/approval-review-gate.ts:138`,
  `workspacePath(binding.spec.cwd, requested, true)` realpaths the missing folder, and the ENOENT becomes the pause
  rationale (the code dates from 09f5963, 2026-09-22, so this predates FX35). Same smoke → row A4.

### Observations (not verdicts)
- C3: in the view, the `\n\n\n` break between messages renders the same as a paragraph break inside a message, so
  where one message ends is not visible (the owner asked for "a whole empty big one between them"). The text the model
  receives is right.
- The usage chip shows review tokens (cache reads included: "53k tok"), not money; the Processes panel shows $0.14.
- A reused reviewer resends its growing history each time: cache reads go 0.5k → 10.9k over 6 reviews. It is retired
  after 12 reviews (REVIEWS_PER_REVIEWER), so this is bounded.
