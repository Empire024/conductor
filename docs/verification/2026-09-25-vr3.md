## REOPEN: local-models-save-tokens, failing scenarios for the next batch

1. **A4 (S7), `local_ask` on a 1 MB log reads nothing on the owner's loaded model.**
   - Setup: a `local_ask` with the prompt "values on the NEEDLE-ALPHA and NEEDLE-OMEGA lines". The file is 1,050,052 bytes of service-log lines (fixture: `.conductor-scratch/vr3/make-1mb.mjs`), and the needles sit at 100 KB and 900 KB.
   - Result: "19 of 19 sections … were not examined (local model failed: Local model request failed with HTTP 400 (exceed_context_size))". It invents nothing, but the tool reads nothing.
   - Reproduced 2/2: the Claude-tab call at 14:20:12Z and a raw call at about 14:22Z (`A4-local_ask-*.json`).
   - Control: a 3 KB slice of the same log answers.
   - Cause: `src/main/local-assist/tools.ts:43`. `MODEL_INPUT_CHARS = 60_000` characters per window, plus line numbers, is fixed whatever the server's context. Dense log text runs far below 4 characters per token, so one window plus the system prompt exceeds `--ctx-size 32768`.
   - Test to write: size windows from the running server's context (`/props` n_ctx, or the configured ctx) at a conservative chars-per-token ratio. On a 400 `exceed_context_size`, halve the window and retry, never skip it. Acceptance: this fixture, on qwen3.6-35b-a3b, finds both needles with part labels.
2. **A5 (new), Claude callers never see a conductor-local answer.**
   - From this Claude Code tab, `local_ask` (2 calls), `summarize_file` and `run_and_summarize` reached the model only as `structuredContent`. Examples: `{"answered":true,"files":[…]}` and `{"exitCode":0,…,"lines":3,"summarized":false}`.
   - The answer, the summary and the "last 15 raw lines" in `content[0].text` are dropped, although `src/main/local-assist/mcp-server.ts:157` returns them.
   - Control: the error path, with content only and no `structuredContent`, reaches the tab as text ("…does-not-exist-vr3.log does not exist"). A raw JSON-RPC call to the same endpoint carries the text.
   - Impact: every successful call looks answered to the caller while giving it nothing. The savings ledger still counts `returnedChars` as delivered.
   - Test to write: an MCP result either carries the text inside `structuredContent` (for example `structuredContent.text` or `answer`), or omits `structuredContent` for Claude sessions. Assert what a Claude Code MCP client surfaces, and check Codex as well.
