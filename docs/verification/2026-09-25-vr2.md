## Harness notes for the next round

- The phone terminal's input API takes base64 (`/api/terminal/:id/input {data}`).
- A stand-in turn that ends at once is never seen working by the phone refresh, so it has no Done
  moment; give it a few seconds.
- A coworker collapses into its controller's tab; read "open" from `tabs.list`, not the DOM.
- `tasks.update` needs an agent credential (the owner's gets "Choose an agent from this project").
- `machines.list` needs an open project.
- smoke-lock has no fairness: a back-to-back chain from another tab re-acquires it before a
  5-second waiter (VR2 waited 11 min behind VR3).
- `safeClose` in spawn mode killed AMD driver helpers (`AMDRSServ.exe`, `amdow.exe`) that the GPU
  process had started under the app, and reported them as leftovers. They are not Conductor's; the kit
  could skip non-Conductor images.
