What the turns established beyond the tables above:

- Codex reports the same `modelContextWindow` of 258,400 for all five models, and Conductor uses it as the capacity with no reserve. The documentation states no window; the value is what the runtime advertises after a turn.
- A Claude model switch inside one conversation keeps the shared prefix (about 17k cached tokens) and rewrites the rest (10–14k cache-creation tokens per switch), which is the cost of changing models mid-session rather than opening a fresh tab.
- Claude's `system/init` carries `model`, `permissionMode`, `tools`, `mcp_servers`, `capabilities` and the version, but **no effort level**; the only effort signal is what Conductor sent (R7).
- The composer's saved settings do not follow a settings write made over IPC (`structured.saveSettings`) while the pane is mounted; the sweep therefore drives the picker and the slider like the owner. Only automation that changes a mounted tab's model from outside the pane is affected.

### Conversation UX correction (2026-09-07)

The main timeline excludes quota/configuration/protocol notices; their original durable events remain in Event log. Actionable errors, unsupported controls and snapshot limitations remain visible. Tools start collapsed; resolved requests are compact expandable rows, with separate wrapper/card classes so borders and padding are not applied twice. Markdown fences, command/read previews and patches use bounded local Monaco tokenization with React-escaped text. No inferred narration or labels.

Opening a Codex pane does not ask for a second provider selection or explicit connection. Typing or opening the searchable model picker discovers native metadata without a user turn. Send waits for an in-progress owned metadata handshake exactly once. Historical reads remain process-free and resume remains explicit. Model/effort changes reach the existing backend; unavailable saved effort is shown explicitly with an opt-in Auto reset. Usage selects latest tokens, cost and account limits separately (not a sum of cumulative snapshots); missing data remains unknown.

This UI revision is fixture-verified in actual Electron for both adapters, including colored code, exact copying, model/effort keyboard interaction, immutable diff review, scrolling and pane lifecycle. Prior Codex live evidence above is unchanged; no additional inference was spent on this revision. See the QA report for exact commands and captures.

### Durability and security

Schema v1 events have Conductor session/runtime/project/workspace identities, native conversation/turn/item/request/parent correlation, local sequence and timestamp. SQLite stores sanitized events and periodic deterministic projections; private immutable artifacts retain original bytes for restore. The reducer is pure and bounded. Unknown events remain inspectable. Replay cannot call a runtime or filesystem API.

IPC checks a known Conductor window, exact trusted renderer URL and main frame, request type, session identity, supported decision scope and runtime incarnation. Files require lexical and canonical workspace checks including junctions/symlinks. Provider processes are launched with argument arrays and separate stdout/stderr, bounded newline/UTF-8 framing and owned-process cleanup. Pending input/approval is expired on disconnect. Undo checks expected post-change bytes, uses per-path host locking and rechecks immediately before write; external writers do not participate in a universal OS compare-and-swap, so this remaining race is stated explicitly.
