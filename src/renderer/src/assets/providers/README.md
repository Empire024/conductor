# Provider marks

SVG provider marks from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), downloaded 2026-09-07. The accompanying MIT license is retained. Brand names and marks belong to their respective owners. The UI uses CSS masks to match the selected theme.

`grok.svg` is not from Lobe Icons: it is an original geometric glyph drawn for Conductor (an open ring with a bar and a four-point spark), used as a neutral stand-in for the Grok provider rather than xAI's own mark.
